# Go
1. Running:
```
go run main.go
```

2. Creating a mod
```
go mod init github.com/YourUsername/YourRepository
```

2. Building
```
go build -o hello
```

# Identifiers
- function starting with lowerCase (Eg: sayHello): means **private**
- function starting with upperCase (Eg: SayHello): means **public**
